### Что проверяют тесты (юнит-тесты для BooksCollector)

1. **Добавление книг:**
   * Успешное добавление новой книги в коллекцию.
   * Запрет на добавление дубликатов (одну книгу нельзя добавить дважды).
   * Ограничение по длине: пустая строка и название длиннее 40 символов не добавляются (использована параметризация).

2. **Работа с жанрами:**
   * Успешное назначение валидного жанра из списка разрешенных (проверено параметризацией для разных жанров).
   * Запрет на установку жанра, которого нет в одобренном списке.
   * Проверка того, что у только что добавленной книги жанр по умолчанию пустой.
   * Фильтрация книг: корректный вывод списка всех книг определенного жанра.

3. **Детская безопасность (без условий в коде):**
   * Разрешенные жанры: успешное добавление книг с легкими жанрами («Мультфильмы», «Комедии») в список для детей (использована параметризация).
   * Запрещенные жанры: строгое исключение книг с возрастным рейтингом («Ужасы», «Детективы») из детского списка (использована параметризация).

4. **Список «Избранное»:**
   * Успешное добавление существующей книги в избранное.
   * Запрет на добавление в избранное книги, которой вообще нет в каталоге.
   * Успешное удаление книги из списка избранного.

5. **Изолированные проверки геттеров (по требованию ревью):**
   * Прямая проверка метода `get_books_genre` на корректный возврат всего словаря книг и их жанров.
   * Прямая проверка метода `get_list_of_favorites_books` на корректный возврат всего списка избранного.
